# 语音转动画 · SOP 故事地图版

> **这份和《语音转动画-SOP.md》是同一个流程的两种讲法。**
> - 《语音转动画-SOP.md》= **原理版**（六关 · 「你在干什么 → 为什么非做不可 → 只动手这一件 → 产物 → 怎么算过关」），回答**为什么这么做**。
> - 本文件 = **故事地图版**（进度看板），回答**现在卡在哪、下一步点什么**。
>
> **怎么用**：打印出来用笔打勾，或者整段复制进飞书 / Notion / 滴答清单当 checklist。
> 每个「活动」是一个阶段，阶段内的任务**按顺序做**（同阶段内有并行标注的除外）。
> ⚠️ 任务前的 ☐ 改成 ☑ 的**前提**是：**你亲眼见过它的产物**，不是"我觉得应该没问题"。

## 活动 1 · 装好环境（一次性，只做一次）

| 序号 | 活动 | 状态 | 任务 | 备注 |
|---|---|---|---|---|
| 1 | **装好环境**（一次性） | ☐ | 1. 装 Node.js 18+ | 本仓库工具全部是 `.js` / `.mjs` / `.cjs`，无构建步骤，不需要 npm install 整个仓库 |
| | | ☐ | 2. 装 Python 3.11+ 并建一个独立虚拟环境 | 转写要用 faster-whisper；**别装到系统 Python 里** |
| | | ☐ | 3. 在 venv 里装依赖 `faster-whisper` `numpy` `Pillow` | 对比度分析、缩图、抽帧统计都要用 |
| | | ☐ | 4. 装 Google Chrome | 渲染走「系统 Chrome + puppeteer-core」，**不下载 Electron 那一套 Chromium** |
| | | ☐ | 5. 装 ffmpeg 并确认在 PATH 里 | 终端敲 `ffmpeg -version` 能出版本号才算好 |
| | | ☐ | 6. 装 `puppeteer-core` | `npm i --no-save --no-package-lock puppeteer-core`（或直接跑 `node kit/check_env.js --install --yes`）；或设环境变量 `RENDER_CORE_PUPPETEER=<绝对路径>` |
| | | ☐ | 7. 克隆本仓库到本地 | `git clone https://github.com/mlf631666711-cloud/Voice-to-animation.git` |
| | | ☐ | 8. 装中文黑体（推荐思源黑体 / 阿里巴巴普惠体） | ⚠️ **字体不进仓库**（体积 + 授权），必须自己装；缺字体 → 画面文字变方块，而且**判据不会报错** |

**✅ 过这个活动的标志**：随便找个终端，`node -v`、`python -V`、`ffmpeg -version` 三条都有输出。

## 活动 2 · 让片子里有声音

| 序号 | 活动 | 状态 | 任务 | 备注 |
|---|---|---|---|---|
| 2 | **让片子里有声音** | ☐ | 1. 写口播文案 | 一段话讲一件事；**别在文案里写画面提示**（那是分镜表的事） |
| | | ☐ | 2. 用 TTS（或真人）生成配音，存成 `voice.wav` | 放工程目录下，**别放桌面** |
| | | ☐ | 3. 量配音时长 | `ffprobe -v error -show_entries format=duration -of csv=p=0 voice.wav` |
| | | ☐ | 4. 转写，拿到**逐词**时间轴（不是逐句） | 用 faster-whisper，**档位 medium**；模型给真实实体名做 prompt（品牌名/型号），否则专有名词必错 |
| | | ☐ | 5. 人工校对字轴 | 重点核专有名词和数字；**这一步省了后面全歪** |
| | | ☐ | 6. 把「配音时长」抄到分镜表头上 | 全片时长 = 配音时长 **+ 1.0 秒**（末尾留一口气） |

**✅ 过这个活动的标志**：你手上有一个 `voice.wav` 和一个 `asr.json`（每句话 + 每个词的开始/结束时间）。

> ⚠️ **本仓库不含全局转写脚本**（那是各项目自带的 `_asr.py`，跟各自的素材格式耦合）。用自己的转写工具即可，**只要产出逐词时间轴 JSON** 就能接下游。

## 活动 4 · 把配音切成画面（写分镜表）

| 序号 | 活动 | 状态 | 任务 | 备注 |
|---|---|---|---|---|
| 4 | **切成画面**（写分镜表） | ☐ | 1. 按**语义**切镜，不按字数均分 | 一屏讲一件事；切点落在**词与词之间的静音**上 |
| | | ☐ | 2. 每镜从镜头卡里选一个动效 | `node kit/shotcraft/pick.mjs`（157 张镜头卡 + 术语库 558 条） |
| | | ☐ | 3. 查术语库确认这个动效怎么写、怎么说 | `node kit/shotcraft/term.mjs` —— 拿到的是**可执行参数**，不是形容词 |
| | | ☐ | 4. **填满六个运镜字段**：`cam` / `cam_amp` / `cam_ease` / `camkeys` / `depth` / `accept` | ⚠️ **缺一个，生成器直接报错中止**（这是故意的） |
| | | ☐ | 5. 用描述词校验器过一遍 | `node kit/check_wording.js` —— 专治「卡片飞进来」「字一个个出来」这类模糊描述 |
| | | ☐ | 6. 存成 `spec.json` | 可照 `kit/templates/spec.example.json` 抄结构 |
| | | ☐ | 7. 自检：每个元素都要有入场锚点 | 锚点必须绑到**词轴**（`asr[i].words[j].start`），不是段边界均分 |

**✅ 过这个活动的标志**：一个 `spec.json`，能被 `new_project.js` 接受而不报错。

|---|---|---|---|---|
| 5 | **生成骨架** | ☐ | 1. 跑脚手架 | `node kit/new_project.js --spec spec.json --out my_proj` |

| | | ☐ | 3. 元素入场时间绑到词轴 | 找 TODO 里的 `asr[0]` 那类锚点 |

**✅ 过这个活动的标志**：浏览器里打开工程 HTML，能看到画面、能动、元素该出场时出场。

## 活动 6 · 渲染出片

| 序号 | 活动 | 状态 | 任务 | 备注 |
|---|---|---|---|---|
| 6 | **渲染出片** | ☐ | 1. 跑渲染 | `node _render.js`（内部走 `kit/render-core.js`） |
| | | ☐ | 2. 看产物规格对不对 | 分辨率 / 帧数 == `时长 × 帧率`（差一帧都算错） |
| | | ☐ | 3. 确认音画时长一致 | **成片时长 = 配音时长 + 1.0s**，实测差值 `\|\|Δ\|\| ≤ 0.02s` |
| | | ☐ | 4. ⛔ **合成时禁用 `-shortest`** | 用 `-shortest` 实测会少 4 帧（349 vs 353），**末尾 0.12s 画面静止而人声还在播** |
| | | ☐ | 5. 要做双版本（无音效 / 有音效）时：**画面只渲一次**，第二版用 `-c:v copy` 只换音频 | 重渲一遍画面 = 多花一倍时间，而且两次结果可能不完全一致 |
| | | ☐ | 6. 抽一帧看有没有黑边 / 白屏 | 起播遮罩没隐藏就会出一片白，而且**零报错** |

**✅ 过这个活动的标志**：一个能正常播放的 `demo.mp4`，声音和画面对得上，末尾不塌。

## 活动 7 · 让门禁放行

| 序号 | 活动 | 状态 | 任务 | 备注 |
|---|---|---|---|---|
| 7 | **过门禁** | ☐ | 1. 跑总审判器 | `node kit/trial.js <工程.html 或 成片.mp4>` |
| | | ☐ | 2. 看 8 条 P0 红线 | `RUNTIME` 能跑 / `PURE` 纯函数 / `MASK` 遮罩 / `BLANK` 空帧 / `SAFE` 安全框 / `ZERO` 零报错 / `OVL` 重叠 / `EDGE` 越界 |
| | | ☐ | 3. 有红灯就修，**修完重跑** | 别只看它"报了啥"，要看它"为什么这么判" |
| | | ☐ | 4. 直到退出码 = 0 | 退出码 0 才算可交；**只打印 FAIL 不改退出码的工具不算门禁** |
| | | ☐ | 5. 可加专项：版面 `layout_check.js` · 安全框 `boxchk.js` · 对比度 `contrast_check.js` | 字幕底边 ≤ 880（净空红线 y=900） |

**✅ 过这个活动的标志**：`trial.js` 退出码 0。

> ⚠️ **判据要有牙**：挑一条判据，**故意把对应的东西做错一次**，看它会不会变红。
> 不变红 ⇒ 这条判据是摆设，别信它给的绿。**这一步不能省。**

## 活动 8 · 用眼睛验收（这一关没有替代品）

| 序号 | 活动 | 状态 | 任务 | 备注 |
|---|---|---|---|---|
| 8 | **肉眼验收** | ☐ | 1. 从成片抽帧（首帧 / 中段 / 末段，各抽几帧） | 只抽一帧等于没看 |
| | | ☐ | 2. 打一张**接触印样**（多帧拼一格）整体看 | 一眼就能看出"哪段画面没内容" |
| | | ☐ | 3. 做**同尺度 A/B**：成片抽帧 vs 页面同帧截图，两边都对齐到 1920×1080 再逐像素比 | 这是唯一能抓出"画面错但判据全绿"的动作 |
| | | ☐ | 4. 关键帧放大看细节（安全框 / 字幕净空 / 参考线有没有烧进去） | 细虚线、三分框这类在缩略图里**根本看不见** |
| | | ☐ | 5. 换个没参与制作的人二审（8 个维度各打分） | 目标 **≥90 分**；自己给自己打分不算数 |

**✅ 过这个活动的标志**：你**亲眼**看过成片的关键帧，而且说不出"这里其实有问题但算了"。

> ★ **为什么这关不能省**：本项目的实测统计 —— **9 个典型缺陷里有 8 个是"零报错、判据全绿、画面是错的"**。
> 唯一会报错的那个反而是最好查的。**能不能发现问题，取决于你有没有把成片抽帧摊开看。**

## 附：最容易死的七个地方（按发生频率）

| # | 死法 | 症状 | 预防 |
|---|---|---|---|
| 1 | 起播遮罩没隐藏 | 成片一片白，**零报错** | 渲染前确认遮罩已关；抽一帧看 |
| 2 | 用了 `-shortest` | 末尾画面静止但人声还在 | 合成命令里搜一遍 `-shortest`，有就删 |
| 3 | 字体没装 | 文字变方块 | 装好中文字体；**判据不会报错** |
| 4 | 时长按"预计"填 | 画面比人声快/慢 | 时长**必须从配音实测**（ffprobe），不是估 |
| 5 | 运镜字段留空 | 生成器直接报错（这算好的） | 六个字段一个不许空 |
| 6 | 判据没牙 | 全绿但画面错 | 故意做错一次，看它会不会红 |
| 7 | 分镜按字数均分 | 一屏话说到一半就切 | 按语义切，切点落在静音上 |
