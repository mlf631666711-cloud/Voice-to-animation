# 音效获取指南

> **一句话**：本仓库**不含任何音频文件**（授权 + 体积两个原因，见 §五）。
> 需要音效时，去下面这些站点自己下 —— 清单里的**全部是免费可商用**的，按「省心程度」排好了序。
>
> 许可口径核实日期：**2026-10**。（授权条款会变，正式商用前请回站点复查一次当前条款。）

## 三、三个会让你翻车的坑

### 坑 1 · Freesound 不是「一个许可」，是一个许可**混装池**

同一个搜索结果页里会同时出现 `CC0`（随便用）、`CC BY`（必须署名）、`CC BY-NC`（**禁止商用**）。
企业宣传片 / 广告 / 带商单的视频里用了 NC 的素材 = **侵权**，而且肉眼完全看不出来。

**做法**：搜索时在 Filters 里把许可勾成 **Creative Commons 0**，只拿 CC0 的结果。
拿了 CC-BY 的，就**在成片说明或片尾留一行署名**（作者名 + 来源链接 + 许可名），别省。

### 坑 2 · 「免费下载」≠「可商用」

`Free` / `Royalty-Free` / `Copyright-Free` 是三个不同的东西：

- **Free** = 下载不要钱（作者仍保留版权，可能限制商用）
- **Royalty-Free** = 不用按次付版税（**不等于免费、不等于免署名**）
- **CC0 / 公有领域** = 最松，随便用不用署名

判据只有一条：**看清该文件自己的许可条款**，不是看站点首页怎么写。

### 坑 3 · 音效**不能提交进 git 仓库**

除了仓库体积，更硬的原因是**授权**：Pixabay、Sonniss 等多数站点的条款都写明
**不得把原始素材文件作为独立素材再分发**（`redistribute as standalone files`）。
你下的、你有权用，**不等于**你可以转手再分发。

> 仓库 `.gitignore` 里已默认忽略 `assets/` 与 `*.wav`，音效放在工程目录里不会误提交。

## 四、下完放哪、怎么用（本管线接口）

音效是**第 ④ 环「采素材」**的一部分，也是**双版本成片**的输入（`_nosfx` / `_sfx`）。

### 1. 放到工程的音频目录

```
<你的工程>/
  audio/
    voice_norm.wav        ← 配音（母版，不动增益）
    sfx/
      whoosh-01.wav       ← 你下载的音效，放这里
      impact-03.wav
    sfx_cues.json         ← 贴点表（下一条）
    mix.wav               ← 混音输出
```

### 2. 在分镜表里标锚点

分镜表（`spec.json`）每个镜头可写 `sfx` 字段 —— `[秒, 名字]`：

```jsonc
{
  "t": 3.18,
  "sfx": [3.18, "whoosh"],
  "accept": "转场点必须踩在 whoosh 的峰值上"
}
```

### 3. 写贴点表（`sfx_cues.json`）

```jsonc
{
  "voice": "audio/voice_norm.wav",
  "out":   "audio/mix.wav",
  "voiceGain": 0,
  "cues": [
    { "name": "转场", "t": 3.18, "src": "audio/sfx/whoosh-01.wav",
      "in": 0.30, "dur": 0.60, "peak": -10.0, "fadeIn": 0, "fadeOut": 0.12 }
  ]
}
```

> **增益不要手填**：`peak` 写你希望这条音效达到的峰值 dBFS，混音脚本会自己去量
> 「素材在被裁窗口内的峰值」，反算出该给多少 dB —— 换素材、换库都不用重调。
> （手填 `gain` 的旧版一换素材音量就全错。）

### 4. 出双版本

```bash
ffmpeg -i _v.mp4 -i voice_norm.wav -map 0:v:0 -map 1:a:0 -c:v copy ... _nosfx.mp4
ffmpeg -i _v.mp4 -i mix.wav        -map 0:v:0 -map 1:a:0 -c:v copy ... _sfx.mp4
```

**画面只渲一次**，两条片子只换音轨 —— 省一半时间，且保证两版画面逐帧一致。

## 五、为什么本仓库不带音频

| 原因 | 说明 |
|---|---|
| **授权** | 我们的音效来自第三方免费库，**再分发权不在我们手上**（见坑 3） |
| **体积** | 一条片子的音效动辄几十 MB，进仓库会把 clone 成本推高 |
| **适配** | 音效得跟着片子的节奏选，"一套通用音效包"对谁都不够用 |

所以这里给的是**怎么自己拿到干净音效**，而不是替你把音效打包。
