# 检测标准（可执行判据）

> 给审核员用的数值条款。来源见角色卡 §3 法源表。
> 判不出来（只能"看着还行"）的条目不要写进来 —— 那不是判据，是感觉。

---

## A · 运行时健康

| # | 判据 | 阈值 | 级别 |
|---|---|---|---|
| A1 | 页面加载 pageerror / console.error | 0 条 | FAIL |
| A2 | 全时段 `__frame(t)` 返回或写入的样式值含 NaN / Infinity | 0 处 | FAIL |
| A3 | `window.__frame` / `getInfo` 存在且为函数 | 必须 | FAIL |

**A2 怎么查**：按 1/fps 步长扫全程，对每个受驱元素读 `el.style.transform / opacity / filter`，
正则抓 `NaN|Infinity|undefined`。别只查"元素在不在"—— NaN 进 opacity 是**静默消失**，
探针查存在性会漏。

---

## B · 几何

| # | 判据 | 阈值 | 级别 |
|---|---|---|---|
| B1 | 任意受驱元素 rect 越出安全框 `(52,70)-(1872,1008)` | 0 帧 | FAIL |
| B2 | 主角（唯一实物）在成片全程的可见帧占比 | ≥ 90% | FAIL |
| B3 | 主角最小边长（屏幕 px） | ≥ 画面短边 8% | WARN |
| B4 | 元素互相压叠面积（遮挡主角/文字） | 0 帧 | FAIL |

**B1 的坑**：页面常有常驻装饰（4 角取景角标、顶/底细线）天然落在安全框外沿，
实测能吃掉约 216px。**必须做 A/B 差值**（改前 vs 改后），只看绝对值会永远报警。
判据是"本次改动新增了多少越框像素"，不是"有没有像素在框外"。

**B4 的坑**：老板立过规矩 —— **定帧展示时文字跟模组都必须完全露出，不能遮挡**。
单查各自 rect 不够，要**求交**并算重叠面积。

## C · 对比度

| # | 判据 | 阈值 | 级别 |
|---|---|---|---|
| C1 | 正文文字 vs 其**实际**背景 对比度 | ≥ 4.5:1（AA） | FAIL |
| C2 | 大号文字（≥24px 或 ≥18.66px 粗体） | ≥ 3:1 | FAIL |
| C3 | 白/浅底上的小字不得用中性浅灰 | 禁 `#8FA0BE` 一类，最低 `#B5C2DC` | FAIL |
| C4 | 深底上的灰字标签 | ≥ 4.5:1（实测 `#94A3BE` on 深底 ≈ 1.18 → 禁用） | FAIL |

**C1 的坑**：别拿"设计背景色"算。文字可能叠在渐变、投影、玻璃卡、视频帧上。
要**抽帧取该文字区域的真实像素**算，否则全是假绿。

## D · 时序

| # | 判据 | 阈值 | 级别 |
|---|---|---|---|
| D1 | 元素入场时刻 vs 旁白对应词时刻（W_AXIS / words.json） | 偏差 ≤ 0.15s | WARN |
| D2 | 段落空窗：画面墨量 < 1.5% 且 < 前一帧 60% 的连续时长 | ≤ 0.3s | FAIL |
| D3 | 成片总时长 vs spec.dur | 偏差 ≤ 1 帧 | WARN |
| D4 | 末帧静止（落版镜头收尾） | 末 0.5s 位移 ≈ 0 | WARN |

**D1 说明**：配音驱动的视频里，元素被旁白锁死。固定 stagger 会让元素抢在旁白前面。
正确做法是 delay 取旁白词时刻（语音轴），不是取时钟 gap。
**但**若设计意图就是"先亮相再念"（如大标题），D1 不适用，需在 spec 里写明。

## E · 运镜

| # | 判据 | 阈值 | 级别 |
|---|---|---|---|
| E1 | 偏航角速度峰值 | ≤ 180 °/s | FAIL |
| E2 | 俯仰角速度峰值 | ≤ 120 °/s | FAIL |
| E3 | 加加速度（jerk）峰值 | ≤ 900 | WARN |
| E4 | 切镜接缝处的"假甩镜" | 逐镜头单独算，不拼轨 | FAIL（若拼轨） |

**E4 是硬要求**：镜头之间是**切**不是连续运镜。拼成一条轨后，接缝处机位瞬移会被
角速度门禁读成 1000°/s 级的转向 —— 假报警，因为观众看到的是切换不是甩镜。

**标定参考（实测）**：90° 转向需要 ≥ 1.7~2.0s 才能压在 180°/s 以内。
1.2s 完成 90° 转向，eio 实测 213°/s、qio 276°/s、cio 444°/s、snapo 319°/s —— 全部超。

**hold 守卫**：`aim:'hold'`（冻结朝向）只在机位沿视线方向进退时安全。
段内横向/升降位移 ÷ 初始视距 > 25% → 冻结朝向会把主体甩出画面，判 FAIL。

## F · 动效合规

| # | 判据 | 阈值 | 级别 |
|---|---|---|---|
| F1 | 元素入场起始 scale | ≥ 0.95（永不 scale(0)） | FAIL |
| F2 | UI 尺度动效时长 | ≤ 300ms（抽屉/表单例外 500ms） | WARN |
| F3 | 成组错峰 gap | 30~80ms | FAIL（越界） |
| F4 | 退场时长 | = 入场 × 0.6 | WARN |
| F5 | 退场曲线 | 必须加速离开（前段慢、后段快） | WARN |
| F6 | 呼吸/pulse 类常驻动效 | 必须有 on/off 窗口 | WARN |

**F3 的例外**：旁白锁定的成组元素（逐字跟读等）gap 由语音轴给，不适用 30~80ms。
判定时先确认该组是否旁白锁定。

**F1 的例外**：实物元素（产品/芯片）的"浮现"可以低于 0.95 —— 但必须先证明
抬到 0.95 不会把它顶出安全框（实测芯片 0.90→0.95 会让 S3 揭幕帧越框 +805px）。

## H · 帧级

| # | 判据 | 阈值 | 级别 |
|---|---|---|---|
| H1 | 抽帧数量 | ≥ 12 帧 | FAIL |
| H2 | 基线均匀抽样 + 每个运镜段中点必取（**瞬态段另有 H4 加密要求**） | 必须 | WARN |
| H3 | 数值指标（墨量/质心/四象限/贴边） | 无空窗、无新增越框 | FAIL |
| **H4** | ★ **瞬态段密采样**：入场末帧 / 元素出场期 / 段落交接口，必须有**步长 ≤ 0.05s** 的连续帧覆盖 | 必须 | **FAIL** |

**★ H4 为什么是 FAIL 级（2026-09-14 立 · 明动 L10 v2 现场）**：

**步长 > 瞬态窗口宽度 = 数学上必漏检**，不是"经验不足"。

实测代价：均匀 24 点步长 = `9.52/23` = **0.414s**，而「卖点行出场期文字整段旋转」的窗口只有 **≈0.10s**
→ 采样点**必然从窗口中间跨过去** —— **86 帧全看完也抓不到**（DG-25 现场 `t=5.20~5.30`）。

**三段必密采样**（由 `kit/frame_sheet.py suggest_sample_points()` 归纳，落实为真采帧）：

| 段 | 时间（L10 口径） | 打什么 |
|---|---|---|
| ① 入场末帧 | `0.00~0.50` | 位移 / 旋转落点冲突 |
| ② 本段末出场期 + 段间过渡 | `4.80~5.45` | 出场期旋转 / 位移失控 |
| ③ 下一段揭幕 | `5.45~6.10` | 主元素到位 + 装饰入场 |

参考实现：`_独立脚本/l10_uim_frames.js` 的 **`DENSE`** 数组（实测 **37 点 → 74 点**，`errors=0`）。

⚠️ ⭐ **`kit/frame_sheet.py --auto-sample` 是「选点提示」不是「采样器」** ——
它只在**已有帧里筛选**（`sample = [t for t in suggest if t in frames_by_t]`），**变不出没采的帧**。
用它把审查成本压一个量级可以，**指望它修采样漏洞不行**。

**H 的铁律**：数值指标只能**辅助**，不能替代人眼。
审核员出报告时必须同时提供帧图路径，供人工复看。

**★ 归因顺序**：抓到视觉瑕疵时先问「**这一点被采到了吗**」→ 再问「判据为什么没报」。
跳过第一步就会把**判据覆盖域**问题误判成**采样漏洞**，然后花力气去修错的东西
（实例：两套采样**都采到了** `t=0.40` 的 bug，真因是判据只扫定帧窗口）。

## 复用命令

> ⚠️ **只能用 `审核员/_独立脚本/` 下自己的实现**（角色卡铁律 2）。
> **禁调** `kit/check_*.js`、工程目录下的 `_frames_*.js` / `_patch_*.js` —— 那是制作侧脚本，
> 复用等于让被审对象给自己判卷。G1 / F 这类门禁判据，**审核员必须自己重新实现**。
> 解释器口径统一见角色卡 §六（`whisper_venv`）。

```bash
PY="python"
NODE="node"
AUD="./审核员/_独立脚本"
TMP="./_tmp"   # 临时拼图走这，别塞进 _独立脚本/

# 1. 抽帧 A/B（独立实现）—— 输出 = 基线 24 点 + 段中点 + 关键点 + H4 瞬态密采样三段 = 74 帧/版本
#    落盘：_frames/{new,old}/f_%03d.png + _frames/times.json（下标即时间）
#    ⚠️ 本脚本**不读命令行参数** —— 想改采样点直接改脚本里的 times 构造段
NODE_PATH="./node_modules" \
  "$NODE" "$AUD/l10_uim_frames.js"

# 2. 拼图审查（12 帧/页 · 把 Read 从 74 次压到 7 次）
#    ⚠️ --glob / --times-json 是必须的：本脚本产出的是 f_000.png（时间在 times.json），
#       不传这两个参数会 collected 0 frames
"$PY" "kit/frame_sheet.py" "$AUD/_frames/new" \
  --glob 'f_*.png' --times-json "$AUD/_frames/times.json" \
  --cols 4 --rows 3 --out "$TMP/_sheet_new.png"

# 3. 像素审判（墨量 / 质心 / 四象限 / 贴边 / 两版差异 · 独立实现）
"<whisper-venv>/python" \
  "$AUD/l10_uim_pix.py"
```
